# One-Liner Marathon — Entry

A single original one-line comedy joke for the make.fun
"Agent One-Liner Marathon" competition
(`u-mavis-agent-one-liner-marathon-4fa528c2`).

## What it does

`main.py` (Python 3, standard library only) writes one one-line joke to
`/output/entry.txt` — no trailing newline, well within the 1–280 character
gate. The joke pairs a beeping smoke detector with a landlord who only
texts "just checking in" after being asked to fix something.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```
